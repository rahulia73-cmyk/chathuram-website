# Chathuram Chess Academy website

Website for Chathuram Chess Academy (Hyderabad and online). Pages: Home, Programs, Coaches, Pricing and Contact.

Built from the [Educenter](https://github.com/themefisher/educenter) template by Themefisher (MIT licence, see `LICENSE`).

## Editing content

- **Contact details** (phone, WhatsApp, email, address, map, social links): `source/site.json`. They are used on every page.
- **Optional home page sections** (hidden until filled in, all in `source/site.json`):
  - `kindleLink`: link to the kids' puzzle book on Kindle. Until it is set, the book section says "Coming soon on Kindle".
  - `homeVideoYouTubeId`: the ID of a YouTube video (the part after `v=`) for the "Chathuram in a minute" section. Or put a short `.mp4` in `source/static/videos/` and set `homeVideoFile` to `videos/name.mp4` (YouTube is better for large files).
  - `studentPhotos`: put photos in `source/images/students/` and list them, e.g. `{"src": "images/students/class-1.jpg", "alt": "Students solving puzzles"}`. The "Our students" gallery appears once there is at least one.
- **Pages**: `source/index.html`, `programs.html`, `coaches.html`, `pricing.html`, `contact.html`.
- **Shared parts**: `source/partials/` (menu, footer, call-to-action, program cards, pawn animation).
- **Colours and fonts**: `source/scss/_variables.scss`.
- **Logo and mascot**: `source/images/brand/` (`mascot.svg`, `pawn.svg`, favicons, social preview image).
- **Chess-piece mascots**: `source/images/brand/pieces/` (dark and `-light` versions). Each piece's base shows how it moves. They are generated by `python3 tools/pieces.py`, so edit the shapes there and re-run it.
- **Pawn animation**: the pawn spin-jumps up the 8 level squares, then promotes to a queen, knight, rook and bishop. Markup in `source/partials/blocks/pawn-path.htm` (pieces in the generated `pp-pieces.htm`), motion in `source/js/script.js`, styles in `source/scss/templates/_pawn-path.scss`. It pauses when off screen and shows a still frame for visitors who prefer reduced motion.

- **Scroll strip**: on wide screens a strip of squares runs down the left edge of every page. The pawn hops down it as you scroll and becomes a queen at the bottom. Markup in `source/partials/blocks/scroll-rail.htm`, styles in `source/scss/templates/_scroll-rail.scss`, motion in `source/js/script.js`.

Do not edit `theme/`: it is generated by the build.

## Run locally

```
npm install
npm run dev     # live preview at http://localhost:3000
npm run build   # writes the site to theme/
```

## Publishing on GitHub Pages

`.github/workflows/pages.yml` builds the site and publishes it on every push to `main`.

One-time setup: in the repository on GitHub, go to **Settings → Pages** and set **Source** to **GitHub Actions**.
The site will be at https://rahulia73-cmyk.github.io/chathuram-website/ (update `siteUrl` in `source/site.json` if you add a custom domain).
